# Gráficos sobre el odómetro y el precio de los vehículos

La siguiente aplicación nos permite evaluar dos gráficos (distribución y dispersión) sobre la relación entre el odómetro (kilometraje o cuentakilómetros) y el precio de los vehículos que se tienen en una base de datos de venta de vehículos.
